# IKIOS v1.0.0 Release Notes

**Tag:** `v1.0.0` · **Date:** 2026-07-08 · **Codename:** RC1 — Enterprise Productization

## What is IKIOS?

IKIOS (Industrial Knowledge Intelligence OS) is an industrial AI platform
built for the ET AI Hackathon 2026 (Problem Statement 8: "AI for Industrial
Knowledge Intelligence: Unified Asset & Operations Brain"). It ingests
industrial documents, builds a structured knowledge graph, reasons over
evidence with explicit contradiction detection, generates justified
recommendations, learns from feedback, trains real scikit-learn models, and
exposes a full research/benchmarking framework — seven layers, not a single
chatbot wrapper.

## Highlights of this release

This release doesn't add AI capability — it turns six milestones of working
engineering into a project a stranger can clone, run, understand, and trust
in under 5 minutes:

- **301 tests pass**, zero regressions across the platform's entire history
- **11 architecture documents** with Mermaid diagrams covering every subsystem
- **One-command setup** (`setup.ps1`/`setup.sh` + `run-dev.ps1`/`run-dev.sh`)
- **Real benchmark reports**, not marketing numbers — see
  [docs/benchmarks/README.md](docs/benchmarks/README.md), generated by
  actually running the production code against a seeded synthetic dataset,
  including honest caveats where a result isn't as clean as it might look
- **A curated demo dataset** with hand-labeled ground truth
  (`demo_data/ground_truth.json`) that deliberately exercises contradiction
  detection with a realistic cross-document conflict
- **Full GitHub open-source readiness**: MIT license, CI, issue/PR templates,
  contributing guide, code of conduct, security policy

## Honest gaps (documented, not hidden)

- **No OCR.** Ingestion supports text-layer PDFs, TXT, and MD — not scanned
  documents. See [docs/architecture/ingestion.md](docs/architecture/ingestion.md).
- **ML training labels are synthetic.** Real historical failure/priority
  labels don't exist in this deployment yet; the training/evaluation code is
  real, the labels are documented, seeded, and learnable, not fabricated. See
  [docs/architecture/ml-lab.md](docs/architecture/ml-lab.md).
- **SQLite, not Postgres.** An explicit MVP substitution — every repository
  is behind a `Protocol`, so this is a config change away, not a rewrite.
