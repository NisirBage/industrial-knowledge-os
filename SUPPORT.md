# Support

## Getting help

1. **Read the docs first** — [docs/getting-started](docs/getting-started) for setup,
   [docs/architecture](docs/architecture) for how things work,
   [docs/faq](docs/faq/README.md) for common questions.
2. **Search existing issues** — someone may have already hit the same problem.
3. **Open a new issue** using the [bug report](.github/ISSUE_TEMPLATE/bug_report.md)
   or [feature request](.github/ISSUE_TEMPLATE/feature_request.md) template.

## What to include in a support request

- What you were trying to do
- What happened instead (full error message / traceback)
- Your environment: OS, Python version, Node version
- Whether Docker (Qdrant/Neo4j) was running or the system was in fallback mode

## Response times

This is a portfolio/research project maintained on a best-effort basis, not a
commercially supported product. There is no SLA.

## Security issues

Do not use this channel for security vulnerabilities — see [SECURITY.md](SECURITY.md).
